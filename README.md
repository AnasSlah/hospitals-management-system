# 🏥 Hospital Management & Booking System

A comprehensive web-based system designed to facilitate healthcare by providing a centralized platform connecting patients, doctors, and hospitals. The system allows users to view maps, search for doctors, rate them, and book appointments easily, alongside a powerful admin dashboard for management.

## ✨ Key Features

### 🧑‍⚕️ User & Patient Interface:
- **Login & Profile:** Manage patient data and health information (e.g., blood type).
- **Hospitals Map:** View nearby hospitals and their geographical locations on the map.
- **Doctors Directory:** Search for doctors by specialty, hospital, and working hours.
- **Appointment Booking:** A quick and easy system to request an appointment with the right doctor.
- **Rating System:** Ability to rate doctors and share the patient's experience.

### 🛡️ Admin Dashboard:
- **System Management:** Add and edit hospital and doctor records.
- **Booking Tracking:** Approve or manage incoming appointment requests from patients.
- **Activity Log:** Accurate tracking of user movements within the system (e.g., visiting the doctors or map pages).
- **Access Control:** Secure protection system for administrative data.

## 💻 Tech Stack
- **Database:** MySQL (Relational Database)
- **Languages:** PHP, SQL
- **Frontend:** HTML, CSS, JavaScript (with integrated interactive maps)
